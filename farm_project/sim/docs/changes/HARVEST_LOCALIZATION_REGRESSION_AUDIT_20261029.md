# 10/28 전후 수확 위치추정 조건 비교 — 인계 태그 미사용 유지

## 결론 — 사용자 조건에 따라 정정

사용자는 인계에서 태그 보정을 사용하지 않는다고 명시했다. 따라서 이번 실행의 인계·복귀 중 태그 미적용은 의도한 조건이며, 이를 연결 누락/결함으로 분류하고 재활성화를 권한 앞선 결론은 철회한다. 태그 관련 공통 코드나 설정은 변경하지 않았다.

AMCL 기본 설정·태그 계산 코드의 롤백 증거는 없고, 초기 위치는 정확했으나 인계 복귀 회전에서 AMCL 오차가 약2cm에서6cm로 증가했다. 같은 구간 odom 오차는 최대 약5mm다. **태그 미사용 조건에서 AMCL 추정 오차가 커지는 직접 원인은 아직 확정하지 못했다.** 이전 태그 사용 연속수확과의 조건 차이는 비교의 한계이지, 인계 실패 원인이 태그 연결 누락이라는 증거가 아니다.

아래 태그 관측/오프라인 계산은 진단 사실로만 보존한다. 운영 보정 적용이나 태그 사용 제안의 근거로 삼지 않는다.

## 이번 입력으로 확인한 라이다·지도 조건

현재 HCR 지도와 이전 count_test 지도는 동일 크기/해상도5cm다. 변경179셀은 선별장 영역 x[-7.575,-6.625], y[13.525,14.975]에 국한된다. 수확로봇 복귀 위치는 x≈-6.01/y≈3.24다. 센서가 멀리 있는 새 구조물을 볼 수 있으므로 거리만으로 지도 영향0을 주장하지 않았다.

저장 scan3313개를 같은 시각의 실제 USD 자세와 기록된 라이다 장착변환으로 투영했다. 전체 유효 빔의 평균 exp(-거리²/(2×0.2²)) 점수 기준, 이전/새 지도의 최대 점수차0.00742. 복귀 끝328.05초는 이전0.98240/새0.98533으로 새 지도가 실제 관측과 더 잘 맞는다. 같은 새 지도에서 Y -5cm는0.98338/+5cm는0.98427로 실제0.98533과 매우 비슷하다.

이는 반복되는 베드 방향에서 수cm 이동을 라이다만으로 강하게 구분하기 어려운 조건과 부합한다. 이 점수는 AMCL의60빔 선택·입자분포·재표본화까지 재현한 결과가 아니다. 지도 변경이 전체 필터 경로에 미치는 영향을 완전히 배제하거나 alpha/sigma 단독 원인을 확정한 것은 아니다.

## 복귀 중 태그가 실제로 보였는가

raw detections: sim/runs/apriltag/5ed4dcb030354cb18fab56816834577b/detections.jsonl.

- 저장 검출에 SEC01 구역 문맥을 명시하고 기존 load_observer/observe로 오프라인 계산:33개 후보가 기하·품질 검사를 통과했다. ROS 보정은 발행하지 않았다.
- USD 기록 범위 안의28개만 같은 sim시각으로 보간 비교: 위치 오차 중앙값2.63mm, 최대5.09mm, 마지막2.94mm. 앞선 AMCL 최종오차 약5.9cm와 구분된다.
- 마지막 일부 태그는 USD 기록 종료 뒤라 정확도 통계에서 제외. candidate33개를 실제 적용33회라고 보고하지 않는다. 태그 관측을 실제로 적용하면 전체 액션이 성공하는지는 아직 검증하지 않았다.

## 다음 조사 방향 — 태그 미사용 조건 고정

인계·복귀에 태그 보정을 추가하지 않는다. 성공 반경5cm도 유지한다. 실패 회전 구간의 동일 scan/odom 입력을 사용해 지도 변경 영향, AMCL 갱신 간격/운동 노이즈, 실제 라이다 반사점과 지도 형상, 주변 운송로봇의 관측 영향을 분리해야 한다.

현재 오프라인 지도 점수는 특정 방향의 구분력이 약함을 보여주지만 필터의 실패 원인을 확정한 A/B 시험이 아니다. 운영 코드·설정 변경과 새 재생 시험은 이번 정정에서 수행하지 않았다.
