## ① 짧은 목표 이동은 시뮬에서만 고쳤는가

아니다. 2026-10-23 `92ad63a`는 공통 `farm_navigation/parallel_approach.py`에서 차체 방향/횡오차/전방 여부를 독립 검사하도록 수정했다. 목표 연결선 각도를 차체 방향 한도와 비교하는 기존 조건을 제거했다.

이후 2026-10-28 `18d0e00`에서 실물 인계 코드를 통합하며 같은 공통 함수에 선택적인 `path_heading_limit`을 추가했다. 기본 None은 기존 해결을 유지한다. 공통 수확 node가 task의 `work_path_heading_limit_rad`를 CorridorNavigator로 전달하고, straight_plan에 연결한다. 실물 담당 프로필은5°를 명시하고 시뮬 task는 미지정해, 공통 구현을 사용해도 실행 조건이 다시 달라졌다.

따라서 처음부터 시뮬 전용으로 고친 것이 아니라, 후속 통합에서 기존 해결과 실물 추가 제한의 정책 충돌을 옵션으로 남긴 상태다. 사용자 공통 판정 요구에 대해 이를 단순 환경 차이로 설명하면 안 된다. 이번 요청은 이력 확인이므로 해당5° 정책은 추가 수정하지 않았고, 공통 적용 방향에 대한 설명을 제공한다. 기존 전방/횡오차/차체방향·충돌검사와 실제 목표 유지.
