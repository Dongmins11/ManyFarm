- 모델의 네 캐스터는 fixed joint로 연결된 구체이며 회전 자유도가 없고, physics material 바인딩도 없음.

명령 전달은 확인되었으나 PhysX가 유지하는 최종 목표나 접촉력까지 측정한 것은 아니다. 고정 캐스터의 마찰은 모델에서 확인한 결함이며, 이번 정지의 단독 원인인지는 재실행 검증이 필요하다.

## 변경

`sim/assets/robots/harvest_count_test/harvest_robot.usd`에만 물리 재질을 추가하고 다음 네 캐스터에 바인딩한다.

- front_left_caster / front_right_caster
- rear_left_caster / rear_right_caster

정지·동마찰 0, 반발 0, friction combine mode `min`. 회전 관절을 생략한 보조 구체의 자유 구름을 단순화한다. 구동 바퀴 마찰과 충돌, 질량, 관절, 주행 서버, Nav2 설정은 수정하지 않는다. 바닥 재질이 `max` combine mode를 강제한다면 이 재질만으로 마찰 0이 보장되지는 않는다.

이 패치는 실제 캐스터의 회전 저항/선회 동역학까지 재현하지 않는다. 향후 실물 주행 성능 비교에는 해당 모델링이 추가로 필요하다.

## 적용

Isaac 및 시뮬 전체 실행을 종료한다. 압축 파일을 프로젝트 루트에 해제하고 프로젝트 루트에서 실행한다.

```bash
python sim/tools/apply_harvest_caster_fix.py
```

별도 의존성·colcon 빌드 불필요. 파일 체크섬이 원본과 일치할 때만 적용한다. 백업은 `sim/runs/patch_backups/`, 실제 적용 이력은 이 문서 옆 `CASTER-FIX-20261006-013-applied.jsonl`에 남긴다.

```bash
source scripts/env.sh sim
ros2 launch farm_sim_runtime all.launch.py \
  project_root:="$PWD" \
  isaac_python:="$HOME/isaac/env_isaaclab/bin/python" \
  device:=0
```

그다음 기존 첫 window HarvestTask goal을 다시 전송한다. 이전 진단 코드를 유지해 이동 여부와 바퀴 위치 변화, 도착 결과를 확인한다. 이전의 `Failed to make progress`가 사라지는지만 보지 말고 실제 월드 위치 이동도 확인한다.

계속 정지하면 새 `sim/runs/drive_diagnostics` 결과를 수집한다. 다음 확인 대상은 물리 엔진의 실제 wheel targets/gains, 바닥 접촉 재질 및 접촉력이다.

## 롤백

Isaac 종료 후 적용 시 출력된 원본 백업 파일 경로를 사용한다.

```bash
python sim/tools/apply_harvest_caster_fix.py --rollback <출력된_원본_백업_파일_경로>
```
