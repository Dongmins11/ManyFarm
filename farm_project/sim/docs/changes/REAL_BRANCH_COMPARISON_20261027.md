## 5. 결론과 권장 통합 순서

**현재는‘공통코드가같고세부설정만다른상태’가아니다.** 양쪽에독립적인기능/수정이쌓였고성공·실패를결정하는실행코드에도차이가있다. 그렇다고실물브랜치를실패하는코드로평가할수는없고,서로다른작업/목표에서검증됐다는뜻이다.

1. 공통주행에양쪽의수정이필요한부분을선별한다. 우리쪽제어시각/경로시간/짧은이동정책을보존하고,실물쪽TF/취소·정지·진단·ActionHandoff잠금개선을의존성과함께검토한다.
2. 목표선각정책은한쪽을무조건복사하지말고같은실패기하로공통기준을확정한다. 실물쪽상세진단값은판정과분리해적용할수있다.
3. 실물전용지도/센서/Spin/통신환경은프로파일로유지한다. 공통기본값의차이는최종적용값으로검증한다.
4. 새인계기능의sim통합은별도작업으로진행한다. 수확팔복귀문제와구분하고하드웨어서비스·센서의시뮬장치대응을확인한다.
