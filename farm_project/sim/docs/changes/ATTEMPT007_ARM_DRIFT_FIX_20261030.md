# 7차 팔 작업 중 차체 밀림: 원인과 9차 적용 조치

2026-10-30 KST. 기준 main `18d0e000` 및 기존 미커밋 변경. 사용자 요청: 8차를 유지하고 7차 원인을 해결하여 9차에 반영. 공통·실물 코드 및 허용치 변경 없음. 커밋·푸시하지 않음.

## 확인한 실패

- 팔 작업 시작 시뮬 시각 347.633초, 중단 요청 452.133초. 약104.5초 경과, 수확 미성공 후 1회 재시도에서 TO_HOME 중 발생했다.
- `student_session.py`는 현재 오른팔 장착점의 **world 위치**와 작업 시작 위치를 비교한다. 2cm 넘게 이동하면 중단한다. 팔이 차체에서 물리적으로 분리됐다는 뜻이 아니다.
- 해당 구간 주행 명령은 모두 0. 차체 world 위치는 약2.4cm 이동했다. 높이·기울기의 큰 변화가 아니라 장시간 누적된 평면 밀림이다. 팔 장착점의 정확한 2cm 초과 순간 측정값은 기존 로그에 없으므로 차체 표본과 동일한 수치로 취급하지 않는다.
- 1~6차의 팔 작업 동안 차체 최대 이동은 대부분1~4mm, 가장 큰 기록 약10.1mm였다. 7차부터 적용한 위치 반복64회가 새 차이였다.

## 발생 이유와 대조

주행 제동을 위해 올린 solver 위치 반복 수는 바퀴만이 아니라 팔까지 포함한 전체 articulation에 적용된다. 따라서 정지해 있는 차체에 반력을 주는 팔의 물리 응답도 바뀐다. 팔 작업에 검증됐던12회까지64회로 바꾼 적용 범위가 문제였다.

7차에서 저장한 동일한 팔 목표·stiffness·속도 한도를 원본 로봇 모델에 재생했다. 주행 명령0, CPU60Hz, 속도 반복4, 동일 평면에서 위치 반복만 비교했다. ROS·영상·과실·베드는 제외한 축소 물리 시험이므로 실제2.4cm의 완전 재현이라고 부르지 않는다.

| 위치 반복 수 | 최대 차체 이동 | 마지막 차체 이동 | 마지막 회전 변화 |
|---|---:|---:|---:|
| 64회 | 6.960mm | 6.960mm | 0.429° |
| 12회 | 1.935mm | 1.876mm | 0.000031° |
| 64회 재대조 | 6.290mm | 6.290mm | 0.391° |

같은 명령에서64회가 더 많이 밀리는 영향은 재확인했다. 개별 접촉 충격량 수준의 PhysX 내부 원인까지 규명한 것은 아니다. 이번 조치는 팔의 기존 검증 조건을 복원하고, 주행 개선 설정의 적용 범위를 좁힌 것이다.

## 수정

- `robotarm_physics.json`: 주행 위치 반복64 유지, `harvest_solver_position_iterations=12` 추가. 속도 반복4 유지.
- `teacher_arm_alignment.py`: 실행 중 PhysX 반복 수 전환 함수. 팔 전용 값이 없는 프로파일은 기존 동작 보존. 실제 getter로 전환 결과 확인.
- `run_fleet.py`: 팔이 busy이거나 양팔 접힘이 확인되지 않으면12회. 작업 종료와 양팔 접힘을 모두 확인해야64회로 복귀. 팔 tick 전에 적용하고 `[arm_solver]`에 시각/적용값 기록. 관절·차체 순간이동 및 정답 위치 제어 없음.
- `student_session.py`: 실패 직전 `SUPERVISOR_FAULT`에 장착점 시작/현재 변환, 이동량·회전량·허용치·단계 기록. 기존2cm/0.05rad 중단 판정 보존.
- `run_single_cycle.py`: 매 시도 소스 스냅샷에 실제 실행 루프와 Student 세션도 포함.
