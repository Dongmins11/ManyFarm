# 선별장 독립 검출 시험 — 검사 영역 위치 불일치

## 시험 결과

실제 농장 통합 시험에서 저장한 RGB 두 장을 원본 HSV 검출기로 재시험했다. **주행·인계·팔 동작·새 Isaac 물리 시험은 실행하지 않았다.** 이번 범위는 원본 영상에 대한 독립 검출 및 ROI 위치 대조다. 원본 과실 위치·카메라 영상·색상 임계값은 그대로 두었다.

| 입력 영상 | 상태 | 기존 ROI 정답 일치 | ROI 아래5px | ROI 아래10px |
|---|---|---:|---:|---:|
| attempt01 | 10개 투입 후, 선별 전 | 1/4 레인 | 4/4 | 4/4 |
| attempt03 | 빨강1개 선별 후9개 잔류 | 0/4 레인 | 4/4 | 4/4 |

각 레인의 맨 앞 과실 색상을 평가했다. 9개 전부를 개별 검출했다는 뜻이 아니다. 정답 색상은 저장된 실제 과실 좌표와 기존 팔의 레인 매핑/집기 후보 범위로 비교했으며 검출기 입력에는 주입하지 않았다. attempt03 정답은 A빨강/B노랑/C빨강/D노랑이다.

- 기존 ROI는 A(185,143,24,10), B(271,143,15,11), C(349,142,18,11), D(435,143,18,12). 세로142~154px의 얇은 영역이다.
- attempt03 기존 영역의 빨강·노랑 픽셀 비율 모두0%. 과실은 영상에 보이지만 영역이 과실 몸체 위쪽에 있어 전부 NO_COLOR다.
- 아래10px 이동만 하면 빨강/노랑 비율 A88.3%/0%, B0%/74.5%, C75.3%/0%, D0%/70.4%. 기존 검출 최소8%를 통과한다.
- 두 영상에서 모두4레인 정답을 맞히는 연속 이동 범위는 아래4~10px다(멀리31~32px에도 별도 일치구간). 크기·HSV 판정은 변경하지 않았다.
- 아래20px는 A/C MIXED가 발생한다. 영상에서 꼭지·광택 주변 색상과 뒤쪽 다른 과실이 함께 들어갈 수 있어 영역을 무조건 크게/깊게 옮기는 것은 권하지 않는다. 세부 색상 혼입 원인별 기여는 추가 확인 대상이다.

## 원인과 권장 조치

현재 영상의 직접적인 미검출 원인은 **카메라 전체 미검출이 아니라 좁은 검사 영역과 실제 과실 투영 위치의 불일치**다. 원본 모델용 ROI를 농장 기존 과실에 그대로 적용하면서 실제 배치/자세에 맞는 여유가 부족하다. 영상 두 장으로 위치 불일치는 확인했으나 형상·장착·카메라 투영 차이 각각의 기여도를 따로 확정한 것은 아니다.

시뮬 전용 ROI에서 Y에+5px를 주는 최소 조정을 우선 후보로 권한다. 원본 전달 ROI와 실물 설정은 보존하고, 연속선별에서 다음 과실이 앞으로 이동해도 일치하는지 검증해야 한다. 이번 요청은 검출 시험이므로 운영 ROI·완료판정·팔 로직은 변경하지 않았다. 3초 NO_COLOR 완료는 재시험하거나 완화하지 않았다.
