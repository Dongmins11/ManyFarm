## 덮어쓰기 위험: 실제 코드에서 확인

A5 참고 파일182개를 현재 로컬과 비교하면 **154개 동일, 2개 차이, 26개 현재 없음**이다. 전달 문서의156개 동일은10/16원본과비교한수치이며현재로컬과는다르다.

현재 로컬의 두 차이는 보존해야 할 수정이다.

1. `student60_mission.py`: `recover_harvest_timeout=True`인 농장 경로에서60초 초과를 즉시액션실패로 끝내지 않고 측정 복귀 후 외부 세션이 재관측·1회재시도한다.
2. `student60_mission_session.py`: 농장 CPU가속 `native_processor` 주입 경로가 있다. 참고본으로 덮어쓰면 사라진다.

추가된 `WindowHarvestMission._route()`는 `RETURN_STOW`이면서 미수확 대상이 남으면 접힘 경로를 잘라 `RETURN_HOME`으로 바꾼다. 현재 timeout 복귀도같은 `RETURN_STOW`를사용한다. 따라서 단순클래스교체는timeout복귀까지가로채어재관측전에다음대상으로넘기거나,마지막대상에서index를증가시켜목록범위를벗어날수있다. 이는호출경로의정적검토결과이며실행재현하지않았다. 정상수확후중간복귀와timeout/재시도/취소복귀를구분해이식해야한다.

`PostReleaseWindowMission`은 `camera_box_settlement_v1` 증거만받는다. 현재어댑터는 `basket_parallel_lasers`를보낸다. 또한A5의카메라장착은설정상 `nominal_candidate_not_measured_mount`이며실측검증된장착위치가아니다. 카메라를추가하면추가렌더비용도측정해야한다.

원본 runner는보존manifest와`original_data_plan.json` 및원본`outputs/.../student_best.pt` 등을검사한다. 해당상대경로를현재실행에그대로사용하는독립배포본은아니다. 체크를삭제해강제실행하는방식은채택하지않는다.
