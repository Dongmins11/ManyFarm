# 통합시험 중 공통코드 문제와 조치 결과

시뮬 설정 변경, 실물·시뮬 값 정합, 시험환경 준비 오류는 제외했다. 횟수는 확인된 기록 기준이며, ‘최소’는 전체 누적 횟수가 미확정이라는 뜻이다. 재발 확인 없음은 전 섹션·실물의 무재발 보장이 아니다.

## 공통코드 결함 수정

| 문제 | 실패 횟수 | 실패 원인 | 조치 | 조치 후 재발 여부 |
|---|---:|---|---|---|
| 제어·도착 판정 시각 불일치 | 관련 105 실패 3회¹ | 제어 위치와 목표 TF의 시각이 달라 도착을 인정하지 못함 | 동일 pose·timestamp로 제어·판정 | 재현 회귀검사 통과. 동일 원인 재발 미확정. 다른 원인의 105는 이후 발생 |
| 긴 경로에도 고정 300초 제한 | 2회 | 27.5m 직진에 약 275초가 필요하나 회전·감속 미반영 | 경로 길이·속도로 제한시간 계산 | 수정 후 SEC10 성공. 확인한 후속 기록에서 동일 원인 재발 없음 |
| 짧은 작업 이동 거부 | 2회 확인 | 허용 횡오차도 가까운 목표에서는 목표선 각도가 크게 계산됨 | 차체 방향·횡오차·전방 여부 독립 검사 | SEC12·SEC16 이동 재시험 2회 성공. 장기 재발 여부 미검증 |
| 스테이션 복귀를 무조건 후진으로 구성 | 최소 1회 | 차체 방향에 맞지 않는 후진 경로에서 103 발생 | 전진·후진 후보 중 가능한 짧은 경로 선택 | 계획 검사 32개 통과. 동일 원인 재발 미확정. 다른 주행 단계의 103은 이후 발생 |
| 운송 인계 후방 진입 조건 누락 | 최소 1회 | 반대쪽에서 접근해 수확로봇이 경로를 막음 | 뒤쪽에서 같은 방향으로 진입하는 경로만 허용 | 후속 SEC02 사이클 성공. 확인한 기록에서 동일 문제 재발 없음. 전 섹션 검증 미완료 |
| 후방 접근 옵션 전달 누락 | 6회 | 중간 래퍼가 rear_approach 옵션을 받지 못해 즉시 예외 | ExclusiveNavigator 옵션 전달 및 호출 연결 검사 | 후속 인계 성공. 동일 예외 재발 확인 없음 |

¹ 관련 3회를 모두 시각 불일치의 결과로 확정하지 않았다. 표의 횟수를 단순 합산해 확정 총횟수로 제시하지 않는다.

## 공통코드의 복구 누락 보완

오차 발생 자체의 근본 원인 해결과 구분한다. 즉시 종료하던 경로에 제한된 복구를 추가한 사례다.

| 문제 | 실패 횟수 | 실패 원인 | 조치 | 조치 후 재발 여부 |
|---|---:|---|---|---|
| 벽 정렬 후 잔차 발생 시 종료 | 최소 1회 | 정지 측정에서 오차가 남으면 재보정 없이 종료 | 현재 관측으로 재계획·재정렬 최대 2회 | 회귀검사 통과. 실제 복구 분기·동일 조건 재발 여부 미확정 |
| 도킹 진입 거리 초과 시 재접근 없음 | 집계 미확정 | 정차 후 마커 거리가 진입 범위 밖이면 복구하지 못함 | 정지·제어권 해제 후 일반 접근부터 최대 2회 재시도 | 후속 도킹 성공. 해당 복구 분기의 재현 검증 부족으로 해결 판정 보류 |
| 인계 복귀 회전 잔차 재보정 없음 | 최소 2회 | 회전 성공 후 정지 방향이 1°를 조금 넘으면 종료 | 위치가 정상일 때 방향 재보정 최대 2회 | 후속 SEC02 복귀 포함 사이클 성공. 확인한 기록에서 동일 중단 재발 없음. 물리적 원인은 미분리 |
| 벽 접근 범위 소폭 초과 시 종료 | 최소 3회 | 기존 20cm 접근 범위를 조금 초과해 인계 중단 | 제한된 짧은 접근 1회 후 재측정 | SEC04 복원 시험 성공. 새 보정 분기 실행 증거 부족으로 재발 여부 미확정 |

## 제외 항목과 한계

- 시뮬/실시간 시계 정합, headless 누락, 물리 밀림·연산주기, 시험 목표·출발 순서·서비스 준비 오류는 제외했다.
- 후진 제어기의 최종 회전 제한도 수정했지만 조사한 실제 103은 주행 단계에서 발생했다. 해당 실패를 해결한 사례로 세지 않았다.
- 수정 후 성공한 항목과 실제 복구 분기 검증이 남은 항목이 섞여 있다. 모두 해결됐거나 재발하지 않는다고 결론 내릴 수 없다.
