## 실제 물리 시험

기존 농장 시험은 유지하고 별도 프로세스에서 실제 예찰 subtree·수확 USD, 기존 물리 설정, 양팔 접힌 자세, CPU PhysX 60Hz로 수행했다. 초기 수확 Y=5m, 예찰 Y=7m; 정지3초→0.1m/s 주행18초→정지2초. 초기 배치 이후 바퀴 drive만 사용했다.

- **정상 방향: 양쪽 전진**. 최초 힘이 기록된 접촉은 예찰 오른쪽 바퀴 ↔ 수확 왼쪽 바퀴. 위치 (-3.7475, 6.0191, 0.0497)m, 물리 tick 753 (시험 시작 후 약 12.55초, 주행 시작 후 약 9.55초).
- 접촉 보고 1477건 중 0이 아닌 충격량을 가진 이벤트 309건, 접촉점 419개. 프레임·접촉쌍 단위 집계이며 독립적인 충돌 횟수가 아니다. 최대 접촉점 충격량 0.1896N·s.
- 시험 끝 예찰 X=-4.0437m: 원래 선에서 38.9cm 이탈, 초기 대비 방향 124.3° 변화. 접촉 이후 열린 루프 속도 명령이 계속된 결과이며 Nav2 사용 시 같은 이탈량이 나온다는 뜻은 아니다.
- 초기 정착 시 전체 충돌 형상의 X 투영 간격은 약 1.4mm뿐이다. 접촉 후 회전으로 X 투영 범위가 크게 겹치는 수치를 실제 침투 깊이로 해석하지 않는다.
- 비교용 예찰 후진 조건: 근접 접촉 보고374건, 비영 충격량0건, 최소 접촉점 separation 약0.93mm. 이는 이번 한 번의 조건에서 물리력이 없었다는 뜻이며 안전 여유가 확보됐다는 뜻은 아니다.

**주의:** summary.json의 passed_each_other는 Y축 앞뒤 순서가 바뀌었는지만 검사한 값이다. 이번 정상 방향은 true여도 안전 통과가 아니다. contact_analysis.json의 collision_free_pass=false 및 실제 힘/이탈 기록을 결과로 사용한다. 근접 접촉 보고만으로 실제 충돌력을 주장하지 않고, 비영 충격량을 별도로 검사했다.

## Nav2와 조치 판단

수확 footprint 측면 반폭0.25m + padding0.02m, 예찰 robot_radius0.10m를 단순 합하면0.37m로, 경로 중심 간격0.33m보다4cm 크다(예찰 추가 padding 미포함). 두 명목 footprint도 나란히 있을 때 겹친다. 이것만으로 실제 Nav2의 감지·정지 여부를 단정할 수는 없으며 센서/회피 시험은 수행하지 않았다.

우선 **이 두 작업선이 겹치는 통로의 동시 진입을 막고 순차 통과**시키는 편이 적절하다. 관제의 기존 구역 점유 규칙이 이 조건을 실제로 차단하는지는 후속 확인 대상이다. 수확·예찰의 작업 거리를 바꾸는 경로 이동은 별도 검토가 필요하다. 이번 작업에서는 운영 경로·제어값·관제를 변경하지 않았다.
