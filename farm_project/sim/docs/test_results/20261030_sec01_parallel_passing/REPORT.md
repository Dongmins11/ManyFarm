## 조건

- task.yaml SEC01에서 예찰 X=-6.655m, 수확 X=-6.015m를 읽어 초기 배치. 중심 간격 0.640m.
- 실제 농장 예찰 subtree와 현재 수확 USD, 기존 팔 물리 설정·양팔 주행 자세 사용. 충돌 형상은 예찰 6개, 수확 117개.
- CPU PhysX 60Hz, 각 로봇 속도 명령 0.1m/s, 초기 Y=5/7m. 정지 3초→주행 18초→정지 2초.
- 초기 배치 후 바퀴 drive로 이동. 실위치는 평가 기록에만 사용하고 경로 제어 입력으로 사용하지 않음.
- 별도 프로세스·빈 평면·ROS/카메라 미연결. 기존 attempt_009를 정지하거나 재설정하지 않음.
