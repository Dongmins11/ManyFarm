## 2. 20초 콘티

7컷을 독립적으로 촬영한다. 각 컷의 시작 상태를 바로 배치하고 화면에 필요한 2~3초 동작만 애니메이션한다. 수확의 파지와 투입은 각각 3초로 나눈다.

| 순서 | 최종 시간 | 사용 길이 | 장면 | 촬영 각도·화면 | 핵심 동작 | 편집 자막 |
|---|---|---:|---|---|---|---|
| 01 | 00–03초 | 3초 | 농장 전경 | 위에서 약 45° 내려다보는 사선. 8개 베드·스테이션·선별장 포함 | 카메라가 농장 안쪽으로 천천히 전진 | ManyFarm |
| 02 | 03–06초 | 3초 | 예찰 | 예찰 카메라가 달린 쪽의 전방 사선. 로봇과 작물 동시 표시 | 베드를 따라 짧게 이동 | 작물 예찰 |
| 03 | 06–09초 | 3초 | 과실 파지 | 과실 높이에서 집게와 열매 근접 촬영 | 접근 → 집게 닫힘 → 과실 분리 | 과실 수확 |
| 04 | 09–12초 | 3초 | 바구니 투입 | 팔·바구니 내부가 함께 보이는 위쪽 사선 | 과실 이동 → 집게 열림 → 투입 | 과실 수확 |
| 05 | 12–15초 | 3초 | 수확·운송 연결 | 두 로봇 바구니 연결부 중심의 측면 사선 | 운송로봇의 마지막 짧은 접근과 정렬 | 수확물 인계 |
| 06 | 15–17초 | 2초 | 운송 | 적재함이 보이는 낮은 전방 사선. 배경에 선별장 | 과실을 실은 운송로봇이 짧게 이동 | 선별장 운송 |
| 07 | 17–20초 | 3초 | 선별 | 선별팔·과실·분류함이 보이는 위쪽 사선 | 잡고 있던 과실을 해당 분류함에 놓음 | 색상별 선별 |

카메라 높이·각도·이동 거리는 촬영 구도의 시작값이다. 현재 자산 크기, 관절 범위, 통로와 가림을 확인해 조정한다. 농장·경로 좌표를 새로 추정해 고정하지 않는다.

```text
기존 관절 자세를 경유점으로 활용하고,
중간 이동에서 팔이나 과실이 설비를 관통하지 않도록 확인해.
```

- 각 원본의 앞 1초를 제외하고 콘티의 사용 길이만큼 순서대로 연결한다.

- 첫 장면 편집 문구는 `ManyFarm / 시뮬레이션 연출 영상`, 이후 자막은 콘티 표의 짧은 문구를 사용한다.
- 동작 소개 영상이므로 성공률, FPS 성능, 실제 처리시간 같은 수치는 영상에 추가하지 않는다.
- 프레임 시퀀스는 렌더·인코딩 방식에 필요하면 보존하되 필수 전달 영상 7개와 구분한다.

## 6. 완료 확인·인계

- 7개 영상의 해상도, FPS, 프레임 수, 재생 가능 여부를 확인한다.
- 각 컷의 시작·중간·끝과 동작 구간을 재생해 가림·관통·외형 누락·멈춤·순간이동을 확인한다.
- 로봇이 바닥 위에서 움직이고, 파지 이후 과실이 집게를 따르며, 투입 이후 과실이 바구니·분류함 안에 있는지 확인한다.
- 03의 끝과 04의 시작에서 동일 과실·파지 자세의 연속성을 확인한다.
- 원본 자산과 공통 코드에 의도하지 않은 변경이 없는지 확인한다.
- 확정 설계 변경은 `docs/DECISIONS.md`, 구현·실행 상태는 `docs/PROJECT_STATE.md`, 시뮬 변경은 `sim/docs/CHANGELOG.md`에 기록한다.
- 확인 수준을 소스 검토 / 과거 기록 / 이번 직접 실행 / 미검증으로 구분한다.
- 이번 사용자 요청은 이 기획 문서의 GitHub 게시를 승인한 것이다. 이후 촬영 도구·대용량 영상의 추가 commit/push는 해당 작업의 별도 지시와 저장소 정책을 따른다.
