# 운송·배출·선별 연속 장면

촬영용 결정적 기하 애니메이션이다. 실제 자율 도킹·하역·선별 시험 성공이나 접촉 동역학 결과로 사용하지 않는다.

## 설정과 연결

- 생성기: [build_continuous_v4.py](settings/build_continuous_v4.py), 주 설정: [06_07_transport_sorting.json](settings/06_07_transport_sorting.json).
- 30 fps, 원본 12초/360프레임. 0~12초의 경계 키프레임 361개를 선형 시간 보간하며 행렬 회전은 Slerp한다. 편집 사용 구간은 원본 `[1,11)`초다.
- [05 최종 적재 상태](settings/handoff_continuity_state.json)의 `final_cargo_matrix` 6개를 그대로 시작값으로 읽는다. Handoff_01~06의 원본 ID·색·크기를 유지하며 Handoff_07은 처음부터 사용하지 않는다.
- 실제 4레인을 유지하고 중앙 B/C에 각 3개를 넣는다. B는 H02 노랑/H04 노랑/H05 빨강, C는 H01 빨강/H03 빨강/H06 노랑이다. H03 빨강과 H04 노랑을 각각 한 번 집고, 나머지 4개는 레인에 남는다.
- 선별장·팔·차량·과실·카메라·조명에는 같은 강체 변환을 사용한다. 기존 V3 선별장 중심 `(-5.4,13.1)`을 `(-5.4,11.8)`로 옮기고 Z축으로 180도 돌린다. 하우스·필름·베드·태그는 숨기거나 수정하지 않는다.
- 카메라는 GUI 비교로 채택한 F(높은 사선, 35 mm) 구도다. 실제 영상 검수는 별도 GUI 결과를 따른다.

## 기하 근거와 확인 범위

- 원본 transport USD의 `box_tilt_joint` +Y축/0~45도, `side_lid_joint` -Y축/0~90도와 원본 local joint frame으로 FK한다. 상부 덮개 양쪽과 pinion은 연속 장면 내내 0이다. 원본 모델의 관절 제한을 바꾸지 않는다.
- 손목은 먼저 아래 45도 중간 자세를 거친 뒤 분류함 앞에서 아래 20도로 바꾼다. 실제 분류함 뒤벽 상단 0.745 m 위인 0.82 m에서 놓고, 0.13초 동안 팔을 정지해 과실이 집게를 벗어난 후 복귀한다.
- HCR 원본 USD의 6관절·TCP·집게 연결과 제한을 읽어 IK/FK한다. [실측 관절 정보](settings/06_07_source_joint_geometry.json)에 각 축·연결·제한을 기록한다.
- 원본 선별장 설정의 0.5 m 경사 길이/0.225 m 높이, 0.12 m 레인 유효폭, 실제 분류함 경사를 사용한다. 회전된 과실의 전체 메시 정점과 원본 경사판·받침대 상판을 함께 사용해 접촉 높이를 구한다. 바구니 안에서는 기울어진 좌표계로 높이를 보정한 후 접촉 위치를 다시 계산한다. 회전각은 경사·평면의 이동거리 합/과실 메시에서 얻은 대표 반지름으로 계산한다.
- 초기 상층 과실이 하층과 동시에 출구로 몰릴 때 닫힌 덮개에 최대 약 25 mm 들어가는 문제를 발견했다. 상층 배출을 늦추고 하층이 빠진 자리로 중력 낙하하도록 변경했다. 현재 계산의 덮개 초과는 0이다.
- [과실 기하 검사](settings/06_07_convex_fruit_audit.json): 렌더 시점의 회전된 원본 메시 볼록체 쌍 교차 0건, 레인 측벽 최소 여유 26.69 mm, 경사면 지지 여유 1.10 mm, 9~12초 과실 행렬 변화 0. [전체 모션 근거](settings/06_07_motion_evidence.json)에 프레임별 6개 위치·소속과 기구 상태를 남긴다.
- [독립 기구 검사](qa/06_07_independent_geometry_audit.json): 361개 키프레임에서 과실–기구 차단 이벤트 0, 팔–설비 차단 이벤트 0, 관절 한계 초과 0이다. 보수적 볼록체 경고 1건은 [원본 삼각면 검사](qa/06_07_support_triangle_audit.json)에서 실제 면 침투 0으로 확인했다. 집게가 닫혀 잡고 있는 동안의 패드 접촉과 비물리 TCP 표시체는 따로 분류한다.
- 수치 검사는 이산 키프레임 범위다. 연속 시간의 전체 swept collision, 강체 접촉 solver, 마찰·충격·자율 제어는 검증하지 않았다. 실제 영상과 프레임 가독성은 [MP4 검수 기록](qa/06_07_transport_sorting-mp4-review.json)을 따른다.
