# 04–06 바구니·과실 연출 근거

- 재현: `python3 sim/runs/presentation_video_revision_v3_20261104/settings/build_handoff_v3.py` (farm_project에서 실행). 저장한 원본 과실 mesh 꼭짓점과 seed `20261104`를 사용한다.
- 원본 USD·공통 로봇 코드·기존 촬영 폴더는 수정하지 않는다. 새 바닥 외형과 복제 과실은 GUI stage의 session layer에만 설치한다.
- 원본 수확 로봇의 바닥 링크에는 렌더할 메시가 없어, 기존 `box_floor_v3.usd`의 Plus/Minus 두 패널을 원래 개폐 링크 아래에 연결했다. 회색 불투명 재질을 적용한다. 바닥 메시만 기존 링크 아래에서 5 mm 올려 상단 z=0.506 m를 기존 옆벽 하단과 맞물리게 했다.
- 바닥 개폐는 기존 `box_bottom_left_joint`, `box_bottom_right_joint`의 실제 USD 관절 프레임을 사용한다. 닫힘 0 → 각각 0.105 m, 월드 +X/−X 방향으로 슬라이드한다. visibility로 바닥을 제거하지 않는다.
- helper 초기화 중 숨긴 로봇 부모 아래 `MakeVisible()`를 호출하면 USD가 형제 바디들을 숨기는 문제가 재현됐다. 바닥 자체 visibility만 `inherited`로 설정하도록 고쳤으며, 숨긴 부모 조건에서도 기존 root/바디 visibility 변화 0건을 확인했다.

## 04 투입

- 이전 채택 44도 카메라, 03 종료와 동일한 시작 관절·과실 부착 행렬, 팔 경로를 유지했다.
- 놓임 이후는 9.81 m/s² 낙하를 30fps로 베이크한다. 원본 과실 메시의 회전·크기를 반영한 최저 꼭짓점이 바닥과 맞닿는 높이에서 안착한다.
- 원본 과실 크기나 농장 ID를 변경하지 않았다.

## 05 인계

- 원본 농장 과실을 촬영용으로 복제한 7개(빨강 4, 노랑 3). 원본 스케일과 재질을 보존하며 복제본의 운영 집계 속성은 차단한다.
- 상하 바구니 중심은 월드 `[-6, 3.65]`로 맞춘다. 운송 root는 `[-6, 3.714, 0]`, yaw=π/2이다.
- 첫 1초 유지, 이후 0.65초 동안 패널 개방. 실제 열린 간격에 따라 1.321~1.496초에 과실들이 낙하를 시작한다.
- 240Hz 중력·회전·보수적 메시 AABB 접촉 계산을 30fps로 저장했다. 하부 바닥 반발계수는 0.12, 접촉 뒤 속도·각속도는 감쇠한다. 네 과실은 바닥, 나머지 세 과실은 그 위에 안착한다.
- 하부 바닥 첫 접촉은 1.525~1.700초. 마지막 1초는 계산된 안정 자세 그대로 유지한다.
- 낙하 중 등속 이동이나 구간별 smoothstep을 쓰지 않는다. 패널만 smoothstep 개방, 과실은 계산된 프레임별 행렬/Slerp 연결이다.

## 06 연결 및 검증 범위

- 05 마지막 7개 과실의 `cargo_box` 상대행렬을 그대로 06에 사용한다. 수량·색상·크기·적재 자세를 보존하며 상대행렬 계산 오차는 0이다.
- 기존 0.35m 짧은 주행과 바퀴 회전을 유지하고, 선별장/팔은 공통 촬영용 `station_transform.json`의 동일 변환을 적용한다.
- 오프라인 검사: 151개 05 키프레임에서 상·하부 바구니 벽 범위 초과 0, 과실 AABB 관통 0, 바닥 침투는 부동소수 오차 5.6e-17m, 원본 스케일 오차 3.3e-16. 마지막 3.5→4초 이동 0.
- 일부 원본 Cube의 authored extent에 치수와 scale이 중복되어 BBoxCache가 잘못된 축소 bounds를 보고한다. 바구니는 실제 Cube `size × world transform`, 과실은 실제 Mesh points로 확인했다.
- 접촉은 보수적 AABB 근사로 과실 실제 표면 사이 미세 간격이 있을 수 있다. 전체 로봇 충돌 검사, 실시간 PhysX 시험, 자율 인계 성공 증거는 아니다.
- GUI 시작/끝 05와 06은 직접 열어 확인했다. 05 높은 후보의 시작/48프레임 낙하/149프레임 안착을 직접 열어 확인하고 최종 구도로 채택했다. 바닥판 개방과 하부 과실이 이전 구도보다 잘 보이며 바퀴·차체·태그도 잘리지 않는다. 최종 채택 및 MP4/중간 접촉 프레임 검수는 최종 README를 따른다.

- 이동 clone의 Model native instance도 세션에서 풀었다. 재시작 후 강한 초기 위치 과실상은 사라졌고 낙하·안착이 보인다. 프리뷰에 남던 희미한 색 흔적의 렌더 내부 원인은 확정하지 않았다. 최종 연속 MP4의 1.8초 이후와 마지막 프레임을 직접 확인했으며 상부가 비워지고 아래 바구니에 과실이 남는 모습이 명확하다. 근거: `qa/05_handoff-mp4-keyphases.jpg`, `qa/05_handoff-mp4-review.json`.
