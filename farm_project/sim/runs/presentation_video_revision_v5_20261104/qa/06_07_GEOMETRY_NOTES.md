# V5 7개 연속 장면 — 기하 검산

대상 요청 SHA256: `aac95d9fd82dab6f14b498843b01d47b528bffcdcc97fb096fa4603c9ceab0d3`

이 문서의 판정은 **촬영용 궤적의 이산 기하 검사**에 한정한다. 실제 GUI/MP4의 자연스러움·가림·베드 비노출 판정은 별도 영상 검수 기록을 따른다.

## 변경과 연속성

- V5 인계의 실제 Bullet 안착 결과를 `handoff_continuity_state.json`에서 받아 7개 각각의 `cargo_box` 상대행렬을 그대로 시작 상태로 사용했다. 기존 6개 궤적에 7번째를 추가하지 않았다.
- 같은 원본 Handoff_01~07, 빨강4/노랑3, 메시·색상·크기를 유지한다. 모든 키프레임에서 7개가 존재하며 숨김/스케일 애니메이션이 없다.
- B 레인: H07(빨강), H06(노랑), H02(노랑). C 레인: H03(빨강), H05(빨강), H04(노랑), H01(빨강). 원래 네 레인 설비 중 중앙 두 레인을 사용한 혼합3+4이다.
- 새 적재는 모두 바닥 한 층에 누운 자세다. AABB가 겹친다는 이유로 이웃을 상층 지지대로 취급하던 V4용 처리를 제거했다. 중앙 과실은 이웃 사이의 여유를 지난 뒤 레인에 정렬하도록 새 경로를 구성했다.
- 누운 과실을 V4의 동일한 닫힘 값으로 집으면 손가락이 몸통을 관통했다. 원본 메시와 원본 집게 형상을 이용해 파지 방향/간격을 탐색했다. 빨강 H03은 수직축 50°, jaw 4.5mm, 노랑 H06은 수직축 50°, jaw 5mm와 10mm 높은 파지점이다. 접근/상승점을 추가하고 옆 과실의 레인 간격을 확보했다.
- H03은 5.60초 집어 6.43초 놓고, H06은 7.38초 집어 8.16초 놓는다. 각각 7.20초/8.933초에 분류함에서 정착한다. 9~12초는 같은 정지 상태이며 투입부에 5개가 남는다.
- 앞문 개방 시작 1.80초부터 복원·닫힘 완료 5.60초까지 3.80초다. 상부 뚜껑은 전체 연속 장면에서 닫혀 있다.
- 선별장·팔·운송·과실은 `06_07_scene.json`의 동일한 강체변환을 사용한다. 카메라/조명은 root가 GUI로 선정한 B안을 사용한다.


## 범위와 한계

- 05 인계의 Bullet 동역학과 달리, 이 연속 장면은 원본 메시 지지면을 따른 **기구학 베이크**다. 횡방향 경로와 구름 감쇠는 촬영용으로 지정했으며 접촉력·마찰력으로 생성한 강체 동역학 결과가 아니다.
- 원본 메시/장비 Cube를 렌더 시점마다 검사했다. 프레임 사이 연속 충돌, 모든 비-Cube 장비 메시, 완전한 동역학 안정성까지 검증한 것은 아니다.
- 화면의 자연스러움·반사 잔상·가림은 숫자만으로 판정하지 않는다. 요청에는 렌더 누적 초기화와 프레임별24회 안정화가 포함되며 실제 영상의 확인이 필요하다.
- V3/V4 결과, 원본 USD, 운영 지도/좌표/공통코드는 변경하지 않았다.
