## 4. 05 인계 — 수량 보존과 자연스러운 낙하

### 수량과 연속성

- **V3의 기존7개(Handoff_01~07, 빨강4/노랑3)를 모두 사용한다.** “6개를 맞추기 위해1개 제거” 요구는 폐기한다.
- 처음 보이는7개가 모두 운송 바구니 안으로 들어가야 한다. 처음부터 하나를 숨기는 방법도 이번 요구의 해결이 아니다.
- 프레임 도중 visibility/opacity/scale 변경, 컷 뒤 개수 감소, 순간이동, 바닥 아래 이동, 복제 과실로 교체를 금지한다.
- 원래 과실 모델/색/크기를 보존한다. 기존6개 배치에1개를 겹쳐 넣거나 크기를 줄이지 말고 실제 바구니 공간을 확인해 새7개 초기 적재와 안착 자세를 구성한다.
- 운송 뚜껑은 받는 동안 열려 있어야 한다. 전량 안착→수확 바닥 복원→운송 뚜껑 닫힘 순서로 연결하고, 뚜껑이 과실을 누르거나 관통하지 않게 한다.
- 마지막7개 각각의 `cargo_box` 상대 위치·회전·크기를 저장하고06·07의 시작 상태로 그대로 넘긴다.

### 운동 연출

수직 낙하 자체를 없애라는 뜻이 아니다. **모두 같은 직선으로 미끄러져 내려와 지정 위치에서 멈추는 인상을 없앤다.**

1. 회색 하부 바닥이 열리면서 지지가 풀리는 실제 순서에 따라 과실별 낙하 시작이 조금씩 달라진다.
2. 낙하 속도는 중력에 따라 증가한다. 초기 자세와 바닥/과실 접촉 때문에 각기 다른 축으로 조금씩 회전한다.
3. 바닥 모서리·다른 과실·운송 바구니에 닿으면 실제 접촉 방향에 맞게 옆으로 밀리거나 튕긴다. 임의의 공중 횡이동/산포 효과를 추가하지 않는다.
4. 착지 후 짧게 구르거나 흔들리고 감쇠하며 정착한다. 큰 공처럼 반복해서 높이 튀거나 마지막 프레임에서 정렬된 자세로 스냅하지 않는다.
5. 기존 바구니 벽/불투명 바닥과 과실 간 접촉을 확인한다. 같은XYZ 궤적을 시간만 달리 복사하는 방식은 사용하지 않는다.

실제 미션을 기다릴 필요는 없다. 촬영용 소규모 장면에서 바구니/열리는 바닥/7개 과실의 짧은 강체 동작을 계산해 베이크하고, 촬영 때는 확정 궤적을 재생하는 방식을 우선한다. 실제 동역학을 쓰지 않는 대안도 접촉·회전·감쇠가 화면에서 납득되어야 하며, 사용한 방식을 기록한다. 전체 로봇 주행/펌웨어/자율 미션 재시험으로 확대하지 않는다.

### 카메라·편집

- 기존 인계 구도를 출발점으로 삼되, 상부 바구니의 개방부→낙하 공간→하부 바구니 안착부가 읽히도록 필요한 만큼 조정한다.
- 바구니 측면3/4 구도에서 적당히 내려다본다. 수직 탑뷰로 낙하 깊이를 없애지 말고, 너무 낮춰 바구니 벽에 낙하가 전부 가려지게 하지 않는다.
- raw5초, 사용구간 `[1,4)`초 안에 전량 낙하·안착·덮개 닫힘이 읽히도록 구성한다. 중요한 낙하를 잘라 길이를 맞추지 않는다.
- 04→05/05→06 전환은 과실이 움직이는 중간을 겹쳐 소실처럼 보이게 하지 않는다. 안정 구간에서 짧게 전환하고, 디졸브가 잔상을 만들면 컷으로 연결한다.
- 실제 MP4를 정상속도와 느리게 모두 확인한다. 숫자/행렬 검사만으로 “자연스러움 통과”라고 쓰지 않는다.

## 5. 선별장 — 베드 없는 작업 공간으로 이동

- 현재 구도는 화면 왼쪽에 베드/작물이 보여 재배 구역 한복판처럼 보인다. **선별장 위치와 카메라를 함께 다시 정한다.**
- 하우스 끝쪽 또는 측면의 비어 있는 작업 공간을 먼저 찾는다. 카메라는 재배 구역 쪽에서 작업 공간/하우스 끝벽·측벽을 향하게 하여 베드가 카메라 뒤쪽에 놓이도록 한다.
- 화면 배경은 비닐하우스 프레임·필름·작업 공간 바닥으로 구성한다. 앞선 하우스 보존 요구는 계속 적용한다.
- 베드의 나무 테두리, 작물/지지대, 통로 너머의 베드까지 **06·07 전체 화면에서 보이지 않아야 한다**. 구석의 작은 베드 조각도 후보 구도 탈락 사유다.
- 베드/작물/하우스를 hide, 삭제, 투명화하거나 벽을 임의로 세워 가리는 방법을 쓰지 않는다. 실제 촬영 위치와 시선으로 해결한다.
- 기존 설비와 주변 여유 공간을 확인해 위치를 고른다. 확인하지 않은 월드 좌표를 확정값으로 사용하지 않는다.
- 선별장·팔·운송로봇의 도킹 경로·과실 궤적·카메라·조명을 일관된 좌표 변환으로 이동한다. 팔과 설비를 따로 옮겨 도달 관계를 깨뜨리지 않는다.
- 촬영 전용 세션의 재배치이며 운영 지도, station_spawn, RouteGraph, 실제 도킹 좌표나 원본 USD에 저장하지 않는다.
- 실제 선별장 형태/레인/분류함은 유지한다. 작업면과 로봇을 화면 주인공으로 두고, 도킹·열린 앞문·과실 배출·팔 집기·양쪽 분류함이 프레임 안에 남도록 한다.
- 새 후보2~3개에서 도킹 직후/최대 기울임/집기/놓임 프레임을 먼저 비교해 베드 비노출과 동작 가시성을 확인한 뒤 전체 촬영한다.

## 6. 06·07의 7개 연결과 시간

- 상부 뚜껑이 닫힌 접근·도킹→앞문 개방→기울여 **같은7개 전량 배출**→혼합 상태로 구름/안착→팔 집기/색상별 선별을 한 테이크로 촬영한다.
- 이전 혼합3+3은 총7개 보존에 맞게 **혼합4+3**을 출발점으로 조정한다. 실제 레인 길이/폭/팔 도달 영역에 맞춰 두 묶음을 잡고 색을 섞는다. 원래4레인 설비를 바꾸지 않는다.
- 일곱 번째를 바구니에 남겨두거나 선별장 도착 전에 없애지 않는다.7개 모두 투입부까지 자연스럽게 배출되어야 한다.
- 인계에서 계산된7개 적재 자세를 출발점으로 새 배출 궤적을 만든다. 7번째만 고정6개 궤적에 얹어 관통시키지 않는다.
- 약8초의 동작 구간에서 기존처럼 빨강1개·노랑1개를 직접 집어 해당 분류함에 놓는다. 이후 **5개가 투입부에 남는다**. 잔량도 계속 화면/장면에 존재해야 한다.
- 수량 기준: 인계는 `수확 바구니 + 낙하 중 + 운송 바구니 = 7`; 이후는 `운송 바구니 + 배출 중 + 레인 + 집게 + 분류함 = 7`.
- 앞문 개방~기울임~배출~복원~닫힘은 기존처럼 약4초 이내. 전체 raw12초/360프레임, 사용구간 `[1,11)`초, 최종15~23초 동작과23~25초 동일 화면 엔딩을 유지한다.
- 도킹·배출·선별 사이에 컷/디졸브를 넣지 않는다. 마지막0.8초 페이드 이전에는 과실/설비를 개별적으로 흐리게 하지 않는다.
