# 라이다 기준 측정 준비 — 2026-10-20

사용자 승인 범위: 성공한 반경0.1m 후진 곡선 다음 동작을 위한 이동 없는 기준 수집·분석.
공통 모듈 wall_reference.py는 ROS와 무관한 NumPy 기반 벽 추정이다. 전체 스캔을 base 좌표로
변환한 뒤 명시한 방위각 영역을 분석한다. 고정 seed 후보 직선/TLS, 지지율/점수/길이 검사를 한다.
거리(m), 벽을 향한 법선 방향(rad), 잔차, 프레임간 변동을 기록한다. 자동 화단 식별은 아니다.
영역/분석 임계값은 입력으로 지정한다. 기본1cm 잔차는 분석 후보용이며 정렬 허용 오차가 아니다.

수집기는 기존 설치 PoseProvider/MotionMonitor를 직접 재사용하며 패키지 경로를 섞지 않는다.
전체 scan(비유한 값은 null), 센서→base TF, odom/map TF, 속도, 발행 footprint와 TF를 기록한다.
map TF는 없는 경우 오류를 기록하며, scan/odom/footprint/필수 TF 실패나 움직임은 실패로 종료한다.
실패 시에도 부분 JSONL과 capture_result.json을 보존한다. 기본8초, 유효10프레임 이상 필요.
일부 스캔만 처리하며 원본 메시지 시각/scan_time/time_increment를 보존한다. 정지 수집용이다.
발행 footprint는 padding 적용 여부를 여기서 단정하지 않는다. 실제 외곽과 비교 후 간격 계산한다.

기준 자세: 기존 경로상의 중심에서 이상적인90도 회전을 마친 자세. 사용자가 실제 자세를 확인해야 한다.
후진 곡선 끝 자세를 자동 기준으로 등록하지 않는다. 측정 자체는 현재 정지 자세에서도 가능하나
그 결과가 이상적인 목표라는 의미는 아니다. 분석 결과 approved_for_motion=false를 고정한다.
기준 벽 거리·방향으로 벽을 따른 종방향 위치까지 복원할 수 없다. 전진/복귀 시험은 후속이다.
