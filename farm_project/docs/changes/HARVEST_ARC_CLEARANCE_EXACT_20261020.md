# 곡선 사전 검사 정확한 셀 비교 — 2026-10-20

## 근거
실측 입력 harvest_arc_clearance_probe.tar.gz에서 기존 검사 -0.0063096m 재현. 기존 80개 자세에서 패딩 포함 사각 footprint와 실제 사각 셀의 교차 없음. 기존은 셀 반대각선 14.142mm와 샘플 간 여유 5.157mm를 셀 중심 거리에서 차감했다.
고밀도 별도 분석에서 계획 곡선과 셀 사이 최소 약 0.711mm, 시작 대비 약 50.7도. 실제 하드웨어 오차를 포함한 안전거리라는 뜻이 아니다.

## 변경
- farm_navigation/arc_clearance.py: 정확한 사각형 교차/거리 비교. 위험 셀 값 >=254(unknown 포함) 유지.
- 입력 경로의 각 구간을 일정 곡률/일정 twist 구간으로 해석. 기존 transfer_arc.arc_path의 원호를 그대로 보간하며, 경로 생성 코드는 수정하지 않음.
- 구간 중앙의 정확한 거리에서 차체 모든 점의 반구간 이동 상한(중심 호 길이/2 + footprint 외접반경*회전각/2)을 차감. 양수이면 전체 구간의 분리를 확인. 불확실하면 둘로 나눠 반복.
- costmap 경계에도 동일 이동 상한 적용. 접촉, 겹침, 잘못된 입력, 세분화/계산 한도 초과는 거절.
- test/test_arc_clearance.py 추가.
- 문서 갱신. 실제 구현 변경은 공통 모듈 한 파일이며 실물 전용 복제 없음.

## 보존
실제 발행 footprint와 기존 패딩, 0.1m 곡선 경로, 속도, 모터, 주행 Nav2 설정, 지도, 태그, 벽 순차 정렬 코드는 변경하지 않음. Nav2 실행 중 충돌 검사 유지. 제로 이하 여유를 허용하는 임계값 변경 없음.
공통 함수를 사용하는 시뮬레이션에서도 같은 계산 적용. 반환값은 실측 벽 거리나 정확한 최소 거리가 아니라 연속 계획 구간의 보수적 분리 하한이며, 이전 숫자와 동일 의미/동일 크기로 비교하면 안 됨.

## 검증
- 단위 검사 12개: 장애물/unknown, 접촉, 정확 거리, 샘플 사이 직진/회전 충돌, costmap 이탈, NaN/중복 꼭짓점, 계산한도 차단, 좌우 원호 중점.
- 실측 실패 입력: 기존 -0.0063m 재현, 새 하한 +0.00007479145m로 통과. 별도 고밀도 최소거리 약 0.000711m보다 보수적인 값.
- 동일 실측 입력에서 경로/footprint를 장애물 쪽 x+0.003m 이동한 변형은 겹침으로 차단.
- 로컬 재생 약 0.08초. 로봇 계산 시간은 별도.
- ROS 실행 및 물리 동작 검증 미실시. 통과한 정적 costmap은 이후 센서 변화/주행 오차를 보장하지 않으므로 실행 중 충돌 검사는 그대로 필요.

## 적용 및 범위
해시로 기존 버전을 확인하고 다른 변경이 있으면 중단. PC Git 브랜치 확인, 원본 백업, 문서 추가. 로봇은 Git을 사용하지 않는다.
이 패키지의 run_pc.bash는 PC에만 적용하며 로봇 접속/이동 없음. 로봇 반영은 원본 PC 백업 후 별도 수행하고 실제 import 경로/해시 확인 필요. Python 모듈이므로 이 변경만으로 C++ 제어기 재빌드 불필요. 반영 후 새 plan 필요.
