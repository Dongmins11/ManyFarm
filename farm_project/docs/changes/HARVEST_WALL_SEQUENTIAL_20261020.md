## 그대로 유지하는 값과 동작
각도 허용오차 1도, 거리 허용오차 5mm, 최소/최대 전진 0.006/0.01 m/s, 최소/최대 회전 0.03/0.05 rad/s, P 이득 거리 0.4/각도 0.8, 입력 유효시간, 이동한도, timeout, 충돌 검사 모두 유지.
정지 판정은 기존 선속도 0.005 m/s·각속도 0.02 rad/s 미만 기준을 재사용. 정렬 유지시간은 기존 dwell=0.5s를 재사용하고, 새 관측 시각이 진행해야 충족된다.
기존 경로 주행, 곡선, 모터 드라이버, 일반 Nav2 설정, 지도 및 태그 보정은 변경하지 않는다.
옵션 미사용 시 기존 동작 유지. 추가 로직은 공통 벽 제어기에서 사용하므로 환경별 코드 복제 없음.

- 실제 변경 C++ 헤더를 GCC -Wall -Wextra -Werror로 컴파일하고 검사 108개 통과(기존 44개 포함).

- 양쪽 방향 7개 초기 각도에서 이상 운동 모델 수렴 및 순차 모드 동시 전진/회전 출력 없음 검사.
- Python/Bash 구문 검사. 설정은 bool 하나만 추가됐음을 비교.
- ROS 빌드 및 옵션 실제 로딩, 취소·충돌 차단의 ROS 동작, 실물 정렬 효과는 이 환경에서 검증하지 않았다. 취소·충돌 처리 코드는 변경하지 않았다.

## 적용
PC 기존 네 파일의 SHA256이 예상 버전과 일치해야만 수정. 모든 파일 확인 후 백업 및 적용. 재적용 시 같은 파일은 건너뜀. 다른 변경이 있으면 덮어쓰지 않고 중단.
PC 전용 검증은 임시 build/install에서 수행하며 로봇에 접속하거나 Goal을 보내지 않는다.
실물 적용 및 동작은 별도 단계. 과거 plan을 재사용하지 않는다.
