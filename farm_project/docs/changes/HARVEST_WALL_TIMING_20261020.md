# 벽 관측 시각 진단 보완 — 2026-10-20

## 확인 근거
- 로봇 벽 제어기 configure 및 plan 성공. 실제 execute에서 입력 시각 오류 wall 발생, 취소·정지 확인 성공, 기존 설정 해시 유지.
- 무이동 8초 검사에서 측정 나이 124.9~282.5ms, 수신 후 경과 최대142.9ms. 해당 검사에서는 오류 미재현. 최초 오류 원인 확정 아님.

## 변경 두 파일
- wall_observer_node.py: ROS 구독 큐를 BEST_EFFORT KEEP_LAST 1로 명시. 기존 최신 1개 처리 큐와 일치시켜 적체 시 과거 스캔 대기를 줄임. 정상 상태에서 지연 감소를 보장하지 않음.
- 동일 관측기: 측정/수신/발행 시각, 큐 대기, TF 조회, 벽 계산 시간 JSONL 기록. 종료 KeyboardInterrupt 처리 및 try_shutdown. 기존 scan stamp 유지.
- wall_trial_runtime.py: 수신 시각과 검사 시각을 보존하여 수신 전 지연과 수신 후 경과를 구분. 0.3초 측정 나이 제한 그대로, 정수 나노초 비교로 경계 반올림 오류 제거. plan --observe-seconds 8 지원, 결과 요약 및 원시 기록 저장.

## 공통 구조 및 영향
공통 wall_reference/WallTracker/PoseProvider/MotionMonitor/Nav2Client 재사용. 실물 전용 알고리즘 복사 없음. 시뮬레이션에서도 동일 관측기 사용, ROS 시각은 측정 나이, 단조 시각은 실제 처리 소요시간에 사용. 정지/중복/역행/추적 간격 제한 유지. 큐 적체로 빠진 스캔 때문에 기존 간격 제한이 발생할 수 있으며 이를 숨기지 않음.
기존 주행, 후진 곡선, 제어기 C++, costmap, 지도, 태그, 목표 거리/속도/각도값 변경 없음. 운영 FSM 연결 없음.
