## 근거와 한계
업로드된 실행 기록의 양의 회전 명령 200개 중 163개가 제공된 드라이버의 정수 RPM 변환에서 0에 해당한다(가속도 제한 전 계산). 시작부 odom 적분 최대 약 0.63도, 전체 순회전 약 0.25도. 실제 모터 쓰기 로그/외부 자세 측정은 아님.
후보 최소 속도는 각각 직진 약 0.694RPM, 제자리 회전 약 ±0.745RPM으로 반올림 시 1RPM에 해당. 실제 최소 구동 속도를 측정해 확정한 값이 아니며 기존 상한 내 시험값이다. 동시 전진·회전 시 바퀴별 결과는 달라진다.

## 직접 검증
- 실제 C++ 헤더 컴파일, 44 assertion 통과.
- C++ 제어기 + 제공된 Python 드라이버 가속도/RPM 원문 계산 + 엔코더 정수 모형 648조건 통과. 초기 거리 4.1~150mm, 각도 ±10도, 관측 age 0.1/0.25초, 각도 잡음 0/0.1도, 명령 지연 0/0.15/0.3초. 최대 완료 21.75초.
- 기존 최소값 0 모형은 동일 작은 오차에서 40초 내 완료하지 못함.
- 모형은 마찰/백래시/슬립/실제 모터 제어를 재현하지 않음. 관측 age 검증은 고정 벽 평면 시각 기준이며 움직이는 장애물 모형 아님.
- 기존 충돌 검사와 취소 로직 소스 무수정. 실제 ROS 충돌 차단/실물 이동을 이번 환경에서 실행한 것은 아님.
- PC ROS 빌드·CTest·configure는 run_pc.bash로 사용자 PC에서 확인. 여기에는 ROS 설치가 없어 완료라고 보고하지 않음.
