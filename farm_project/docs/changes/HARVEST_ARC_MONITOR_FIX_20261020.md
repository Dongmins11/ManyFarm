## 시험용 감시 정책과 근거

선속도 기준은 기존 그대로: 전진0.005m/s, 절댓값0.025m/s 초과 즉시 실패.
측정각속도0.18rad/s 초과가 odom 시각 기준0.10초 지속되면 실패.
0.20rad/s 초과는 표본 한 개도 즉시 실패. NaN/Inf, 시각중복/역행, 표본간격0.5초 초과 실패.
명령의 기존 gate(-0.025..0.000001m/s, -0.001..0.18rad/s)는 그대로이며 C++ 명령상한0.15도 그대로다.

0.10초는 약3개 측정구간에 걸친 지속 여부를 보는 시험 설계값이다.
0.20은 기존0.18에 한정된0.02rad/s 초과대역을 두는 시험용 상한이며, 제조사 안전한계가 아니다.
이 대역을 최대0.10초 허용할 때0.18 기준 추가 회전량은 약0.002rad(0.115도)다.
이는 소프트웨어 판정 전 대역의 계산이며 실제 제동거리나 멈춤시간 보장이 아니다.
반복 짧은 초과도 이벤트로 모두 기록한다. 교대로 나타나는 큰 변동을 정상 운용으로 인증하지 않는다.
실제 재시험에서 속도 이벤트와 정지 결과를 확인해야 한다. 이번 기록이 통과한다는 이유만으로 물리 검증 완료 아님.

정지 기준은 기존 공통 기본값: 선속도0.005m/s 미만·각속도0.02rad/s 미만·0.8초 유지.
최대대기는 이번 시험 기존5초 유지. odom 최신성0.5초와 ROS 시각 진행 검사.
