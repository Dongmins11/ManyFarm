수확 요청 없음

prepare는 접힘 명령이 아닙니다. stop 응답·취소 접수와 최종 Action 결과는 다릅니다. 시험 클라이언트 정리는 팔 정지를 보장하지 않습니다.

초안을 만든 뒤 내용을 확인하고 수확 요청을 보내세요.

수확 요청은 /harvest_01/arm/harvest_task로 직접 보냅니다. 차체 미션·대기열·Pinky 적재량을 갱신하지 않습니다. 동일 업무 ID 재전송은 서버가 거절할 수 있습니다.

이동 없는 배출 시험

배출 시험 모드: 미확인

기존 Pinky 발행기의 transfer_active만 시험용 true로 바꿉니다. 정지는 실제 관측으로 확인합니다. 모드 켜기는 배출 명령이 아닙니다. 아래에서 Discharge를 별도로 요청하세요.

배출 종료·정지 확인 후 모드를 끄세요. 웹 연결을 종료해도 모드는 유지됩니다. 운영 주행·수확·인계 작업이 시작되면 시험 모드는 자동 해제됩니다.

배출·기록 조회·수동 복구

담당자 회신상 현재 Jetson은 Discharge Goal을 거절합니다. 배출 성공을 가정하지 않습니다.

Jetson의 복구 응답만 확인합니다. 이력 삭제·자동 재실행·Pinky 적재량 수정은 하지 않습니다.

01 · 다시 시작할 때
수확 시험 종료
수확 런치·별도 수확 노드·카메라·로봇 브리지를 종료합니다. Nav2와 costmap 메모리도 종료됩니다. PC 더미·운송 로봇은 종료하지 않습니다.
완료 결과의 잔존 PID가 없어야 로봇을 옮길 수 있습니다. 재기동은 자동으로 하지 않습니다.


02 · 스테이션으로 옮긴 뒤
수동 복구 기록
미완료 기록을 백업하고 복구 표시를 해제합니다. 실제 성공·취소 응답을 만들어내지 않습니다. 재기동 후 새 window 도착이 필요합니다.
상태 조회 후에 실행하세요. 실행 중 IDLE 강제 변경은 지원하지 않습니다.


03 · 더미 준비
PC 더미 제어
실제 팔을 제어하지 않는 통신 시험 대역입니다. 로봇·더미를 켠 뒤 복구 → 준비 조회 → 반복 허용 순서로 사용하세요.
더미 후보 설치가 필요합니다. 유휴 상태에서만 적용하며, 관제 expected_count나 실제 적재량을 덮어쓰지 않습니다.


04 · 웹 작업 보내기 직전
같은 작업 1회 허용
마지막에 완료한 수확 ID·좌표·요청 수량이 같은 작업을 300초 안에 한 번 허용합니다. 실행 중 중복 요청과 다른 payload는 거절합니다.
허용 결과에 대상 작업 ID가 표시됩니다. 성공 결과를 확인한 뒤 기존 관제에서 전송하세요.
관제의 미확정 인계 정리·대기열 재개는 기존 관제에서 직접 합니다.
