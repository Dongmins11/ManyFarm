# 반복 시험 콘솔

PC에서 사용하는 운영 보조 도구다. 로봇 종료·수동 복구 기록, PC 더미 준비·수량 변경·동일 작업 1회 반복을 제공한다. 이동/초기위치/운송 명령은 전송하지 않는다.

```bash
cd /home/eunbi/vmany/main/farm_project
python3 robot/tools/trial_console/app.py
```

접속: http://127.0.0.1:8091. 이미 실행 중이면 중복 기동하지 않는다. config.json에는 현장 PC의 외부 더미 경로와 SSH 대상이 있으며 다른 PC에서는 해당 경로를 맞춘다. 기동·종료는 사용자 터미널에서 수행한다.

1. 상태 새로 조회: 실행 프로세스·로봇 상태·odom 정지·더미·관제 차단 상태를 확인한다.
2. 재시작 시 수확 프로세스 종료 → 잔존 없음 확인 → 실제 스테이션 재배치 → 상태 조회 → 스테이션 확인 체크 → 복구 기록. 원본과 이전 결과는 백업한다.
3. 사용자 터미널에서 PC 더미/브리지와 로봇 laun을 켠다. IDLE·정지 및 실제 스테이션 위치 확인 후 vinit, 이어 zen/dzen.
4. 더미 준비 확인. 복구 필요 상태에서만 더미 복구 후 다시 준비 확인한다. 개수 변경은 유휴 시 가능하며 실제 팔의 수량을 뜻하지 않는다.
5. 웹 작업 직전에 마지막 수확 1회 반복 허용. 300초·1회·같은 요청 내용만 허용하며 실행 중 중복은 차단한다. 허용권은 더미 재시작 시 사라진다.
6. 관제 미확정 인계/대기열 정리는 기존 관제에서 사용자가 수행한다. 주행·인계 버튼도 기존 관제를 사용한다.

표시된 정지는 표본 구간의 결과이며 위치 정합 검증을 대신하지 않는다. 오류 응답을 성공으로 처리하거나 자동 재시도하지 않는다.
